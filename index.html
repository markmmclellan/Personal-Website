V-Calc: Pokémon Champions Damage & Speed Calculator

A Showdown-style damage and turn-order calculator for Pokémon Champions, built with React and TypeScript on top of the @smogon/calc Champions ruleset. Pulls live usage data from op.gg via a custom scraper so popular moves, items, abilities, natures and Stat Point spreads apply in one click, supports Doubles with spread-move handling, team import/export from Showdown pastes, and saved presets. Dogeared: Personal Reading Library (PWA)

A mobile-first, installable web app for importing, organizing and reading long-form text. It's a serverless, single-user app built on Cloudflare Workers and D1 (SQLite) with a Vite-built vanilla JavaScript front end, and it runs entirely on Cloudflare's free tier.

  • Security: password login with HMAC-signed, HttpOnly session cookies, constant-time comparison, and per-IP brute-force protection with escalating lockouts and optional email alerts.
  • Safe imports: EPUB, HTML and plain-text import with content sanitized through DOMPurify, plus an HTTPS-only, allowlisted server-side fetch proxy.
  • Offline reading: a service worker with IndexedDB and Cache API storage lets saved material be read without a connection.
  • Library features: reading progress, bookmarks with notes, shelves, series ordering, search, and JSON backup/export.
  • Data layer: a relational schema with foreign keys and cascading deletes, evolved through versioned SQL migrations.
