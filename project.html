V-Calc: Pokémon Champions Damage & Speed Calculator

A Showdown-style damage and turn-order calculator for Pokémon Champions, built with React and TypeScript on top of the @smogon/calc Champions ruleset. Pulls live usage data from op.gg via a custom scraper so popular moves, items, abilities, natures and Stat Point spreads apply in one click, supports Doubles with spread-move handling, team import/export from Showdown pastes, and saved presets. Deployed to GitHub Pages with a scheduled workflow that rebuilds every 6 hours to keep the data fresh.

Self Hosted Local LLM & Interface Stack

An end-to-end local AI environment running on my own hardware. Koboldcpp serves a Gemma 4 12B (QAT) model as an API backend, and SillyTavern provides the front end for session management and prompt customization. I reach it from my phone from anywhere over Tailscale.

Phone Browser, from anywhere
Tailscale WireGuard-encrypted mesh, no open ports
Home PC RTX 5080 16 GB · 32 GB RAM
  • SillyTavern (front end)
  • Koboldcpp (API backend)
  • Gemma 4 12B QAT

Security

I used Tailscale instead of port forwarding, so nothing on my home network is exposed to the public internet. Only my own authenticated devices can reach the model.

What I learned

I originally built it as a coding assistant, but models this small turned out to be poor at coding work. I repurposed it as a general assistant and for recreation, which is where it shines.

Dogeared: Personal Reading Library (PWA)

A mobile-first, installable web app for importing, organizing and reading long-form text. It's a serverless, single-user app built on Cloudflare Workers and D1 (SQLite) with a Vite-built vanilla JavaScript front end, and it runs entirely on Cloudflare's free tier.

  • Security: password login with HMAC-signed, HttpOnly session cookies, constant-time comparison, and per-IP brute-force protection with escalating lockouts and optional email alerts.
  • Safe imports: EPUB, HTML and plain-text import with content sanitized through DOMPurify, plus an HTTPS-only, allowlisted server-side fetch proxy.
  • Offline reading: a service worker with IndexedDB and Cache API storage lets saved material be read without a connection.
  • Library features: reading progress, bookmarks with notes, shelves, series ordering, search, and JSON backup/export.
  • Data layer: a relational schema with foreign keys and cascading deletes, evolved through versioned SQL migrations.
